[View Live Project](https://notify-landing-page-task.vercel.app/)

##  Features

- **Pixel-Perfect UI**
- **Fully Responsive**
- **Light & Dark Mode**
- **Smooth Animations**


## 🛠 Tech Stack

- **Framework**: React.js
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Hosting**: Vercel

## 💻 Running Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/marvakt/NotifyLandingPage_task.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd NotifyLandingPage_task
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

5. **Build for production**
   ```bash
   npm run build
   ```
